# Análise de NPS - Tech Challenge Fase 1 (FIAP)

## Objetivo

Aplicação para leitura, processamento e análise estatística dos dados de Net Promoter Score (NPS), realizando a categorização de clientes (Promotores, Neutros e Detratores) e gerando gráficos explicativos de distribuição.

## Tecnologias Utilizadas

* **Python 3.10**
* **Pandas** (Tratamento de Dados)
* **Matplotlib & Seaborn** (Visualização de Dados)
* **Anaconda / Conda** (Gerenciamento de Ambientes)
* **Docker Desktop** (Conteinerização)

## Como Executar o Projeto

### 1. Execução Local via Terminal (CMD / Anaconda)

Ative o ambiente virtual e execute o script:

conda activate desafio_nps_fase_1
